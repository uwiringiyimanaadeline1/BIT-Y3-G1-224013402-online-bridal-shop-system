# Lookbook photos

The home page gallery has eight Unsplash bridal photos to start. Add your own clothing photos to this folder, then list each file in the `clothingPhotos` array near the top of `assets/js/app.js`, for example:

```js
{src: 'assets/images/clothes/gown-01.jpg', alt: 'Ivory lace wedding gown', caption: 'Soft lace and timeless detail'}
```

The gallery duplicates the photo sequence automatically and scrolls it continuously. You can use local files here or remote image URLs in the same list.
