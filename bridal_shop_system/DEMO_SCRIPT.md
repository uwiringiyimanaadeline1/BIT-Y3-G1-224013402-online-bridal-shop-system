# 2–3 Minute Demo Script

Start Apache and MySQL, import the schema and seed files, then open the project in a browser. For an existing database, import the one-time migrations described in `README.md`.

| Time | Show and say |
|---|---|
| 0:00–0:20 | Open Home. Show responsive navigation and the shorter featured-dress image carousel. |
| 0:20–0:45 | Open Dresses and show the default table, switch to card view, then search by name, color or size. |
| 0:45–1:15 | Sign in as the customer, request an available dress for valid dates, then open My rentals. Point out the calculated total and pending status. |
| 1:15–1:35 | Return to Dresses and show that the requested dress is now marked Rented. Book a fitting from the customer's rental and show it in Fittings. |
| 1:35–2:15 | Sign out and sign in as Manager. Show Manage users, then upload dress photos, preview them, approve a rental, and update a fitting. |
| 2:15–2:35 | Show `schema.sql` with the customer/manager roles, four core related entities and foreign keys, then finish with the README setup and security features. |

Keep the manager password out of the recording. The video itself must be recorded on the local PHP/MySQL setup; it is not included in this source folder.
